# Cloudflare Pages

此分支保留原版游戏产物，在 Pages 构建时生成 dist，避免上传超过单文件限制的 WASM。

Pages 的 Git 构建设置：

| 设置 | 值 |
| --- | --- |
| 生产分支 | cf-pages |
| 框架预设 | None |
| 构建命令 | node cf-pages/build.mjs |
| 构建输出目录 | dist |
| 根目录 | 仓库根目录 |

使用 Node.js 22 或更新版本，不需要安装依赖。不配置构建命令或把输出目录设为仓库根目录，仍会上传原始大文件。

构建优先提供 gzip 压缩载荷，浏览器使用 DecompressionStream 解压并编译；不支持解压或压缩载荷加载失败时，读取每块最多 8 MiB 的原始分片。两条路径都恢复同一份 WASM，不改变游戏内容。压缩载荷使用 .bin 后缀，服务端不要额外设置 Content-Encoding: gzip。

分片采用内容哈希命名，客户端校验长度和 SHA256。构建会验证压缩往返和分片拼接结果，并拒绝输出达到或超过 25 MiB 的文件。以后其他资源超过限制时，构建会指出文件名，避免产生无法上传的部署目录。

更新游戏时，用新的已验证产物覆盖此分支根目录中的游戏文件，保留 cf-pages 构建文件。重新执行构建即可更新压缩载荷、分片、入口和清单；不要手动修改生成的 dist。

原始 WASM 继续保存在 Git 中，实际部署目录不含它。现有 Git 历史和 main 分支保持原样。自定义域名在 Pages 控制台配置，构建不复制 GitHub Pages 的 CNAME。
